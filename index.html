Workflow

  1. Load a model (optional). Pick a pre-trained or local model. The tool uses your GPU if it finds one and reads the class names from the model. You can also add classes yourself with Manage classes.
  2. Create a dataset. Choose a folder of images and click Create dataset. Files are hard-linked where possible, so nothing is duplicated on disk.
  3. Review. If auto-labelling is on, each image is labelled the first time you open it. Fix the shapes, then press Enter to save and move on. Saved images are marked reviewed.
  4. Split. Set train, valid and test ratios in the Split tab and click Auto-split dataset.
  5. Train. In Train and tools, pick a base model and settings, then click Start training.
  6. Export. In Browse, choose YOLO or COCO and click Export.
